    五场景闭环与适配说明

    1. 开工建议

    prepare：问卷 answers.json → 校验条件空间 → router 路由 → 六段建议（算法/停止/可行率/先验/交付口径/噪声）。

    2. 下一批取样

    ask：按当前观测给出下一批待测条件，自动带 plate/well/batch；pending 未回填时会报 E_CONFLICT。

    3. 结果回填

    tell：实测结果按 id 幂等写入 dataset；未知 id 报错不静默忽略；支持 JSON / CSV / TSV。

    4. 交付自查

    delivery：交付清单 + check_integrity + 收尾建议；推荐优先用确认复孔均值。

    5. 看板

    render：只读 run 目录生成单文件 dashboard.html（内联 SVG、无 CDN、无预测造假）。

    6. 导入数据

    粘一个文件路径 → 扫描列画像 → 确认每列角色 → （可选）让模型读表 → 作先验导入并直接落到算法子参数表单。

    离线兜底

    所有依赖在 vendor/；后端不可用时自动回退 EduKit.mockRun，页面不白屏，mock 文本均标注「离线演示」。

    唯一会出网的地方（CONTRACT §9.1）

    工作台默认完全离线。只有「导入数据 → 让模型读表」（POST /api/import/map）会外发，且必须同时满足 --import-llm 开关打开 且 环境变量里有密钥；外发前有二次确认弹窗，只发 表头 + 列画像 + 前 N 行样本（默认 12 行，上限 50），不发整文件。 未开启时返回 E_LLM_UNAVAILABLE，可一键改走离线规则映射（fallback:"rules"），不静默降级。 密钥只从环境变量读，不写盘、不回显、不进日志。

    接口（CONTRACT.md §2）

    GET  /api/bootstrap        首屏元数据（algorithms / prepare_template / scenarios）
GET  /api/runs             已有 study 列表
GET  /api/study?id=<run>  单个 study 快照
POST /api/action           {"action":"prepare|init|ask|tell|delivery|render|override|step|recommend|report","run":null,"payload":{}}
POST /api/run              SSE：meta → stage×4 → delta → （error）→ done

    SSE 帧格式与 EduKit 完全一致，前端解析器不改：EduKit.parseSSE(response)。stage.index 对应 Scenario.stages[index]。

    边界

    • 离线 mock 是预置演示文本，不代表算法输出，也不含任何真实实验结论。
    • AI 只能从注册表里选算法、只能在参数 schema 里改参数；每次路由与覆写都写入 decisions.jsonl。
    • 示例目标是合成/虚构数值；真实结论必须来自真实测量，禁止伪造实验数据。
    • 服务只绑 127.0.0.1、无鉴权、无外网请求。
