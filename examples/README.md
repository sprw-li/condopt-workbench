# 导入示例数据（合成，非真实实验）

这两个文件用于试工作台的「**06 导入数据**」流程（粘路径 → 让模型读表 → 作先验导入）。

| 文件 | 行数 | 列 | 用途 |
|---|---|---|---|
| `history_yield.csv` | 90 | `T, time, conc_M, solvent, equiv, inert, yield, purity, batch` | 干净宽表，走通正常导入 |
| `history_messy.csv` | 40 | 同上 + `note` | 故意带脏值（`n/a`、空 `yield`、全空 `note`），用来演示映射确认与**坏行拒绝要有原因** |

## 重要声明

- **这是合成数据**：`yield` / `purity` 由 `` 里一次性脚本按一个光滑代理函数 + 固定随机种子（20261120）生成，
  **不是任何真实化学实验的结果**，不得当作实验证据、不得进入 README/研究文档的结论。
- 目标列是 `yield`（越大越好），`purity` 可作为约束列（例如 `>= 90`）；
  `batch` 是板号（建议映射为「忽略」，它属于孔板/批次记账，不进条件空间）。
- 想让流程更「真」，把路径换成你自己的 CSV/TSV/JSON/JSONL 即可——默认只允许读取
  仓库根与 runs-dir 下的文件（`--allow-import-root` 可加别的根）。
